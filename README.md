# Web Games Collection

A collection of educational multiplayer web games built with modern web technologies.

## 🎮 Games

### [Rock-Paper-Scissors](./rock-paper-scissors)

A real-time multiplayer Rock-Paper-Scissors game with:
- **Multiplayer modes**: Random matchmaking and private rooms
- **CPU opponents**: 4 AI personalities with different skill levels
- **Multiple formats**: Single round, Best of 3, Best of 5
- **Difficulty levels**: Easy (10s), Medium (5s), Hard (3s)
- **Real-time gameplay**: WebSocket-based instant responses
- **Full TypeScript stack**: Type-safe client and server

**Tech Stack**: TypeScript, Node.js, Socket.io, Vite, SQLite

[View Project →](./rock-paper-scissors)

## 🚀 Getting Started

Each game is in its own folder with complete setup instructions. Navigate to the game folder and follow its README.
